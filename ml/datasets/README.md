# Fair Fare ML datasets

`fare_training_synthetic.csv` is a reproducibly generated synthetic dataset
for local model-development validation. It contains 600 rows generated by
`scripts/generateSyntheticFareDataset.js` with seed `20261011`.

These rows are not real provider observations, live prices, or availability.
They are Lahore-oriented route scenarios generated from Fair Fare's documented
simulation categories with deterministic time/weather variation and small
seeded noise. They must not be presented as real-world fare evidence.

The feature source of truth is `ml/prepare_dataset.py`. The target is `fare`
in PKR. Numeric features include coordinates, route distance/duration, time,
weekend, precipitation, and temperature. Categorical features include
provider/category identifiers and names, normalized vehicle type, zones, and
weather condition/severity. `comparison_id` groups provider rows only for
evaluation and is excluded from model features.

Validation:

```text
node scripts/generateSyntheticFareDataset.js
node scripts/validateFareDataset.js ml/datasets/fare_training_synthetic.csv
```
